# Legacy: prototype xác thực SkillGraph bằng Python và ArangoDB

Thư mục này được giữ lại để tham khảo lịch sử. Ứng dụng tích hợp hiện chạy Backend Node.js tại `../../backend/`; không chạy dịch vụ Python hoặc làm theo cấu hình cũ trong thư mục này.

Các hướng dẫn Python/ArangoDB cũ đã hết hiệu lực. Hãy dùng [runbook dựng máy mới](../../docs/INTEGRATION_RUNBOOK.md), chỉ với một Docker project và volume test riêng. Không dùng credential mẫu cũ; file `.env.example` hiện chỉ có placeholder.
